# `@shurokkha/icons`

Semantic Shurokkha icon aliases shared across applications.

This package owns product-domain icon names such as `ShelterIcon`, `DonationIcon`, and `EmergencyHelpIcon`. Base UI primitives remain in `@shurokkha/ui`.

Use focused subpath imports:

```ts
import { ShelterIcon } from "@shurokkha/icons/shelter-icon"
```
